# 초기 음반·사진 수집 계획과 반영 기록

이 작업은 1995–2004년을 먼저 대조하고 2005–2009년으로 넓힌다. 정규·EP·싱글·컴필레이션·믹스테이프 및 공식 공개를 입증할 수 있는 데모·무료 공개곡이 대상이다. 자료 조사 완료와 모든 음반·사진의 확보는 다른 상태다. 공개 현황은 [앨범 탐색](https://k-hiphop-map.vercel.app/releases/)과 [수집 현황](https://k-hiphop-map.vercel.app/coverage/)에서 확인한다.

## 수집 순서와 완료 기준

1. **기존 목록 대조:** 핵심 아티스트의 발매 명의와 트랙 참여 명의를 각각 안정적인 browse API로 끝까지 조회한다. 총수·고유 ID·페이지 겹침을 검증하고, 실패한 페이지를 빈 결과로 처리하지 않는다.
2. **초기 씬 확장:** 대한민국·Master Plan 시리즈와 Master Plan / Soul Company / Big Deal의 레이블 목록을 우선 수집한다. BLEX, SNP, 신의의지, 한량사, 가라사대 등 DB에서 빠지기 쉬운 후보는 별도 목록으로 관리한다. 제목만 같은 해외 음반은 제외한다.
3. **전체 수록 순서 보존:** 디스크·트랙 번호, 원문 제목·명의, 출처를 기록한다. MR·기악·영상 및 아직 식별하지 못한 참여자도 수록 목록에서는 지우지 않는다. 타 장르·해외 모음집은 목록을 보존하고 한국 힙합 실연자가 참여한 곡부터 연결한다.
4. **곡별 참여 검토:** 실연과 작사·작곡·프로듀싱·스크래치를 구분한다. 그룹·단체 명의를 개인 멤버로 자동 확장하지 않는다. 모호한 역할은 지도 연결에서 보류한다.
5. **판본·활동명 대조:** MusicBrainz release-group, 녹음 ID·ISRC·참여자, 원반과 배급사 자료를 함께 사용한다. 제목만 같은 곡은 합치지 않는다. 확인한 활동명 변경은 이전 URL을 보존하면서 정규 ID에 연결한다.
6. **사진 전수 조사:** 현재 카탈로그의 모든 아티스트에 상태·조사 시점·출처·다음 행동을 남긴다. 새로운 아티스트도 자동으로 조사 대기에 들어간다. 인물·재사용 조건·화질·크롭을 확인한 후보만 로컬 파일로 게시한다.
7. **검증 후 배포:** 데이터 불변 조건, 검색·앨범 상세·수집 현황의 모바일/데스크톱 동작, 공개 출처와 이미지 파일을 확인하고 버전이 일치하는 정적 사이트를 배포한다.

## 사진의 게시 기준

- Wikimedia 파일의 저작자·원본 URL·파일별 라이선스·라이선스 URL을 확인한다. 동명 문서의 사진은 음악 식별자와 인물/그룹 구분을 대조한다.
- 공식 프로필·프레스킷은 후보 출처다. 공식 사이트에 올라왔다는 이유만으로 재게시 권한이 있다고 간주하지 않는다. 별도 사용허락 자료는 `portrait-permissions.json`에 사진별로 기록한다.
- 조사 결과는 `portrait-review.json`, 프로필 후보는 `portrait-source-candidates.json`에 보존한다. 자동 검색·다운로드와 시각 검토 승인은 분리한다.
- `portrait-approvals.json`의 원본 URL과 실제 후보가 일치하고 인물·크롭을 승인했을 때만 공개 폴더로 복사한다. 흐린 무대 원경·가려진 얼굴·잘못된 크롭은 보류하고 대체 사진이나 재편집을 요청하는 다음 행동을 남긴다.
- 그룹 사진은 전체 구도를 유지하며, 사진이 없는 사람도 검색·협업 지도에서 제외하지 않는다. 공개 [사진별 크레딧](https://k-hiphop-map.vercel.app/credits/)은 실제 게시 자산에서 생성한다.

## 계속 조사할 자료

### 2026-10-04 반영 규모

현재 카탈로그는 아티스트 2,756명, 발매 4,017개, 녹음 13,099개다. 이번 반영으로 발매 41개가 추가됐고, 1995–2009년 발매 457개의 전체 트랙 위치를 확보했다. 이 수치는 출처에 있는 수록 목록의 확보 범위이며, 모든 곡의 실연 크레딧 검증 완료나 한국 힙합 전체 음반의 완전성을 뜻하지 않는다.

사진은 기존 160명에서 633명으로 늘었고, 핵심 아티스트는 116/268명에서 120/268명으로 늘었다. 전체 2,756명에 조사일과 결과를 남겼으며 조사 대기는 0명이다. 미반영 2,123명은 사진 미확보 2,027명, 인물·이용조건 확인 55명, 화질·크롭 재검토 41명이다. 추가 사진의 대부분은 기존 카탈로그의 협업 참여자다. 초기 언더그라운드 핵심 인물의 사진은 재사용 근거가 있는 원본 확보가 계속 필요하다.

`data/release-backlog.json`이 미해결 음반의 정본이다. BLEX 1집, SNP 자료, 절정신운 한아의 데모, 대한민국 2003·2004의 실제 발매 여부, 식별자가 확정되지 않은 초기 레이블 목록을 유지한다. 확인하지 못했다는 결과를 음반이 존재하지 않는다는 결론으로 바꾸지 않는다. 소실된 무료 공개곡은 공식 공지·보존 페이지·배포 시점 근거를 확보하기 전까지 확정하지 않는다.

사진은 `unsearched → visual-review → included`를 기본 경로로 삼고 `not-found`, `identity-review`, `permission-needed`, `retry`를 구분한다. 게시되지 않은 모든 항목에 다음 행동을 남기며, 주간 작업에서 오래된 미해결 결과를 다시 확인한다. 조사 실패와 자료 부재를 구분한다.
